# E-Commerce Website Testing Project

## Project Overview
This project focuses on testing an e-commerce website using manual testing, automation testing, and API testing.

## Application Under Test
SauceDemo
https://www.saucedemo.com/

## Testing Types

### 1. Manual Testing
- Login functionality
- Product listing
- Product sorting
- Add to cart
- Remove from cart
- Checkout
- Order confirmation

### 2. Automation Testing
- Tool: Selenium
- Language: Python
- Framework: Pytest
- Automated login and checkout scenarios
- HTML test reports
- Screenshot capture on test failure

### 3. API Testing
- Tool: Postman
- HTTP methods: GET, POST, PUT, DELETE
- Status code validation
- Response body validation
- Automated API assertions
